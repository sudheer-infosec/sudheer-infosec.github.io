# 🛡️ Wazuh SOC Detection Lab — Simulations

This directory contains controlled simulation scripts used to generate security-related activity for the **Wazuh SOC Detection Lab**.

The simulations are designed for an isolated, authorized lab environment and are intended for learning, detection engineering, log analysis, and SOC investigation workflows.
